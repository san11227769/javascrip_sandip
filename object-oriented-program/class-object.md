# OOP has 4 pillars: Abstraction, Encapsulation, Inheritance, and Polymorphism.

Abstraction – Hide unnecessary implementation details and show only essential features.
Encapsulation – Bundle data and methods together and control access to the data.
Inheritance – Create a new class based on an existing class and reuse its properties/methods.
Polymorphism – One interface/method can behave differently depending on the object.
